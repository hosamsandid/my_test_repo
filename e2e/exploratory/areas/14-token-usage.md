# 14 — Token usage

**Scope:** `/token-usage`: time ranges, grouping (agent/team/model/provider/day),

- Grouping switches; totals equal the sum of rows; four token classes have
  distinct colours in all themes.
- Pool instances counted under their role.
- Persona: Member sees own team only (fail-closed), Outsider nothing of others.
