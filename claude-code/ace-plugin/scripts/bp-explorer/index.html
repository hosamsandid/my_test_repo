Technical Glossary

Business-friendly ↔ Technical mapping for the i-SASE Agent framework

Core Concepts

External (Business) Internal (Technical) Description
Agent BriefingPack (BP) A self-contained mission definition with goal, guidelines, acceptance criteria, and escalation rules.
Agent Template Blueprint A reusable, parameterized template from which new Agents can be instantiated.
Agent Instance / Run Claimed BP in Worktree A running execution of an Agent, operating in an isolated environment.
Launch / Start Dispatch The act of sending an Agent to run. Triggers claim protocol and autonomous execution.
Multi-Agent System Parallel BP Dispatch Multiple Agents running simultaneously, each in its own isolated environment.

Agent Lifecycle

External (Business) Internal (Technical) Description
Define an Agent Draft a BP Create the mission definition with goal, scope, and constraints.
Agent is ready BP approved The definition has been reviewed and approved for execution.
Launch Agent Dispatch BP The Agent starts running in an isolated environment.
Agent is working BP in-progress Autonomous execution with periodic heartbeats.
Agent completed BP completed The Agent finished its mission and produced a Merge-Readiness Pack.
Agent reviewed BP reviewed Human reviewer approved the Agent's work.

Supporting Artifacts

External (Business) Internal (Technical) Description
Escalation CRP When an Agent encounters a structural trigger it escalates to a human for guidance.
Delivery Report MRP The Agent's output summary: what was done, decisions made, and artifacts produced.
Escalation Response VCR The human's documented response to an Agent escalation.
Agent Playbook LoopScript (LS) The phased execution plan an Agent follows — strictly sequential phases with gates.
Agent Guidelines MentorScript (MS) Project-wide and team-level rules that all Agents must follow.

Execution Environment

External (Business) Internal (Technical) Description
Agent Environment Git Worktree Isolated copy of the repository where the Agent works without affecting the main branch.
Agent Runtime Executor The general-purpose AI runtime that executes any Agent's instructions.
Agent ID agent-id 8-character hex identifier generated at startup, used in commits and artifact tracking.
Agent Dashboard BP Explorer This web UI — for monitoring Agent status, viewing the mission graph, and interacting with running Agents.
