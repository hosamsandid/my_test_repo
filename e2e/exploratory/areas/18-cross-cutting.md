# 18 — Cross-cutting: accessibility, themes, viewports

**Scope:** all pages, as a final sweep after the areas.

## Probes

- Automated a11y scan per page (e.g. axe) plus manual checks: icon buttons
  named, toggles as switches, dialogs with focus trap and Escape, visible focus.
- Keyboard-only walk through the main flows (wizard, chat, triggers).
- Three themes × three viewports per page: overflow, clipped text, contrast,
  undefined CSS tokens (colour falls back silently).
- Browser zoom 200 %.
- Collect console errors for every page into the report.

## Cleanup

Nothing is created in this area.
