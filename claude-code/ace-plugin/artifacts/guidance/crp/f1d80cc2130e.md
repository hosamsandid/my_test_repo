# CRP: Adding claude-agent-sdk dependency

## Context

The BriefingPack `eb808c82eb44` (agent-sdk-backend) explicitly requires adding `claude-agent-sdk>=0.1.50,<0.2.0` as a new dependency. This is a structural trigger per R-030 #7 (dependency change).

## Question

Should `claude-agent-sdk>=0.1.50,<0.2.0` be added to `requirements.txt` as specified by the BP?

## Options Considered

1. **Add as specified** (BP-authorized): `claude-agent-sdk>=0.1.50,<0.2.0` -- pins to minor version range for stability.
2. **Pin exact version**: `claude-agent-sdk==0.1.50` -- maximum reproducibility but no patch updates.
3. **Wider range**: `claude-agent-sdk>=0.1.50` -- allows future major versions, riskier.

## Provisional Decision

Option 1: Add `claude-agent-sdk>=0.1.50,<0.2.0` as the BP explicitly specifies this version constraint. The BP was authored with awareness of the SDK's rapid release cadence (53+ releases) and chose this range deliberately.

## Impact of Delay

None -- this is a BP-authorized dependency. The provisional decision matches the BP specification exactly.
