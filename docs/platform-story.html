Accenture Agent Studio

A complete platform to build, operate, and scale AI agents as a team — running entirely within your own infrastructure.

Scroll
01

Quick Start

Paste a GitHub URL, hit Enter — done. No wizard, no configuration. The system creates a Working Environment and Agent automatically and redirects straight to the chat.

02

Setup Wizard

On first launch, a guided wizard walks you through five steps — from the AI connection to your first running agent.

03

The Admin Console

A complete management interface at localhost:4000 — everything you need to manage agents, environments, credentials, and integrations.

04

Working Environments

An environment is a reusable workspace recipe. It defines which repos are cloned, which skills are available, which LLM endpoint is used — and applies to every agent built on top of it.

05

Team Setup Wizard

A single workflow creates a complete development team — Business Analyst, Developer, Code Reviewer, Security Reviewer, Test Reviewer, Documentation, and Issue Triage — all connected to the same repository and automatically reacting to GitHub events.

06

Agent Chat

The embedded Matrix chat at /chats is more than just a chat window: agents on the left, the conversation in the middle, and a full observability panel on the right with Session Log, Workspace Browser, and Trigger Editor.

07

Triggers

Agents don't only react to chat messages — they can work proactively on a schedule, via webhook, or on GitHub events. Each agent's triggers are managed in its own Triggers tab.

08

Model Registry & MCP

Manage multiple LLM endpoints in parallel — with connection testing and automatic model discovery. Through MCP servers, agents gain runtime access to wikis, vector databases, or internal APIs.

09

Session & Memory

Every conversation runs in a persistent Claude session context. The agent not only remembers the conversation — it actively writes important facts and events into its own memory.

10

The Full Picture

All platform components — from the Admin Console to the autonomous agent team — in one overview.
