Jira — watch config
← Issues

Which Jira projects the broker polls, and — per project — which events it forwards and which target statuses matter. A watch fires on a transition into any of its statuses; type a status and press Enter to add it (Save adopts a status still being typed); leave the set empty to fire on every status change. A change wakes only the agents that carry a plugin-event trigger for jira — configured per agent in Agent Chat → Triggers.

The status chips apply to status changes only. When you tick more than one kind of event, set Which event on every plugin-event trigger for jira — a trigger with that left blank (and no Only when… filter) wakes on every kind you forward.
